# OFI Momentum Strategy on CME ETH Futures

Code and results for a momentum strategy on CME ETH futures driven by
Cont-Kukanov-Stoikov (2014) Order Flow Imbalance, evaluated on
dollar-volume bars.

The full writeup, results tables, run instructions, and figures live in
[`eth/README.md`](eth/README.md). All code is under `eth/`.
